# PARA Curate: 옵시디언 지식 관리 자동화 가이드

이 시스템은 수집한 자료를 읽고 요약하여 PARA 구조의 적절한 위치로 분류하는 과정을 자동화합니다. 사용자는 자료를 특정 폴더에 넣기만 하면 되고, 이후의 모든 정리는 AI 에이전트가 수행합니다.

### 1. 폴더 구조

시스템이 정상적으로 작동하기 위해 옵시디언 보관소 내에 아래와 같은 구조가 필요합니다.

```text
Documents/joshua/
├── 00-inbox/
│   └── clips/          # 수집된 원본 파일이 들어가는 입구
├── 30-resource/        # AI가 정리를 마친 최종 노트가 저장되는 곳
└── 99-meta/
    ├── draft/          # 정리 과정에서 생성되는 임시 데이터
    │   ├── pending_write
    │   └── done
    ├── assets/         # 논문 그림 등 첨부파일 저장소
    └── digests/        # 날짜별 처리 결과 리포트

```

### 2. 문서 수집 및 사용 방법

평소 자료를 수집할 때는 복잡한 분류 고민 없이 `00-inbox/clips` 폴더 한 곳만 활용합니다. 제목이 없다면 내용을 바탕으로 제목을 생성합니다.

* **Article/Papers/Repo:** 내용을 복사/붙여넣기 해도 좋고, 링크를 그대로 넣어도 됩니다.
* **각종 파일 및 이미지:** 파일과 이미지는 `99-meta/assets`에 저장한 후, `[[...]]` 형태로 링크를 걸어둡니다.

자료가 쌓이면 `Codex/Claude Code`에서 아래 명령어를 실행합니다.

* `para-curate all`: 인박스 내 모든 미처리 클립 정리
* `para-curate <파일명>`: 특정 파일만 지정해서 정리

### 3. 동작 방식

명령어를 실행하면 시스템은 다음 단계를 순차적으로 거칩니다.

1. **데이터 추출 (Extract):** 원본 파일에서 텍스트와 핵심 근거 데이터를 뽑아 임시 팩(Evidence Pack)을 만듭니다.
2. **노트 작성 (Write):** 추출된 근거를 바탕으로 지정된 템플릿(한 줄 정의, 핵심 디테일, 적용 포인트 등)에 맞춰 한글 요약을 작성합니다.
3. **품질 검증 (QA):** 작성된 내용이 원문과 일치하는지, 정보의 깊이가 충분한지 스스로 검사합니다. 통과하지 못할 경우 1회 재작성을 시도합니다.
4. **분류 및 이동 (Organize):** 검증이 끝난 노트를 `30-resource` 하위 폴더로 이동시키고, 인덱스 파일(Digest)에 기록합니다.

### 4. 주요 원칙 및 특징

* **데이터 무결성:** `# Original Content` 영역은 원문 그대로 보존하며 절대 수정하지 않습니다.
* **근거 중심 요약:** AI가 임의로 내용을 생성하는 것을 방지하기 위해, 원문의 구체적인 위치(섹션, 페이지 등)를 근거로 명시합니다.
* **자동 복구:** 실행 중 오류가 발생하거나 품질이 낮을 경우 스스로 수정 프로세스를 가동합니다.
* **최종 보고:** 모든 작업이 완료되면 처리 결과와 요약 내용을 한글 리포트로 제공합니다.

사용자는 `00-inbox/clips`에 파일을 넣고 명령어만 실행하면, 최종적으로 잘 정돈된 지식 베이스를 `30-resource`에서 확인할 수 있습니다.
